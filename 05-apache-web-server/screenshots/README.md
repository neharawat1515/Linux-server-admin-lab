# Apache Web Server

## Objective
Installed, configured, and tested Apache HTTP Server on RHEL.

## Configuration
- Web Server: Apache httpd
- Port: 80
- Document Root: /var/www/html

## Configuration Steps
- Installed Apache using dnf.
- Enabled and started httpd service.
- Allowed HTTP service through firewalld.
- Created a custom index.html page.

## Verification
Verified Apache service status and tested the web page using curl.
