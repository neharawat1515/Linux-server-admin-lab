# Logs & Troubleshooting

## Objective
Inspected system and service logs and performed basic troubleshooting checks on the RHEL server.

## Log Checks
- Reviewed current boot error logs using journalctl.
- Reviewed Apache access logs.
- Reviewed Apache error logs.
- Reviewed recent Apache service logs.

## Troubleshooting Commands
- systemctl --failed
- ss -tulpn
- journalctl

## Verification
Checked failed services, listening ports, and Apache service logs successfully.

## Result
System and Apache logs were reviewed and basic troubleshooting procedures were verified.
