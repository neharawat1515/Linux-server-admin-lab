# System Monitoring

## Objective
Monitored CPU, memory, disk usage, uptime, and running processes on the RHEL server.

## Monitoring Commands
- top
- free -h
- uptime
- ps aux
- df -h
- du -sh /var/log

## Verification
- Checked CPU and memory usage.
- Identified processes consuming CPU and memory.
- Checked filesystem usage.
- Checked /var/log disk usage.
- Verified system uptime and resource status.
