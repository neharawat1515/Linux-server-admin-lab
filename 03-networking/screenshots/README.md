# Networking

## Objective
Configured and verified network connectivity on the RHEL server.

## Network Configuration
- Interface: ens160
- IP Address: 192.168.16.128/24
- Connection Type: Ethernet

## Verification
- Verified interface status using ip addr.
- Verified NetworkManager connection using nmcli.
- Verified internet connectivity using ping.
- Verified DNS resolution using google.com.
